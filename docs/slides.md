# 演示指南（DEMO-001）

> **同源不同形**（01 §原则二）：同一份内容可以有文档版与演示版两个独立表现形式。
> 演示 = 每页一个观点、强视觉、少文字、逐页叙事；**绝不做「文档切页成演示」的机械转换**。
> 演示质量由演示专用视觉组件保证（内置布局 + 3 套主题），不让 Agent 裸写语法碰运气。

## 1. 一分钟上手

```bash
doclight slides talk.md          # → dist-slides/talk.html（自包含单文件）
```

产物双击即可打开（file:// 离线可用），或 `doclight preview --dir dist-slides` 预览。

## 2. 源语法

单个 markdown 文件，文件头 frontmatter（可选）+ `---` 分页：

```markdown
---
title: 演示标题
author: 作者
date: 2026-08-14
---

# 封面主标题

副标题一句话。

<!-- notes: 开场白（演讲者备注，观众不可见） -->

---

<!-- layout: section -->

# 章节页

---

<!-- layout: content -->

## 内容页

- 每页一个观点
- 少文字、强视觉

:::tip
扩展语法（容器/代码块/表格/KaTeX）在演示中同样可用。
:::

---

<!-- layout: end -->

# 谢谢
```

| 元素 | 语法 | 说明 |
|---|---|---|
| 分页 | 行首 `---` | 每页一个分隔（文件头 frontmatter 块不算分页） |
| 布局 | `<!-- layout: cover/section/content/end -->` | 缺省自动：第 1 页 cover，其余 content |
| 备注 | `<!-- notes: 提示 -->` | 观众页不显示；S 键演示者视图可见 |
| 元数据 | 文件头 frontmatter | title / author / date（封面署名行） |

## 3. 布局语义（每页一个观点）

| 布局 | 用途 | 视觉 |
|---|---|---|
| `cover` | 封面：标题 + 副标题 + 作者/日期 | 大标题居中（4.2rem） |
| `section` | 章节转折页 | 大文字居中（3.6rem） |
| `content` | 内容页（默认） | 标题 + 正文，顶部对齐 |
| `end` | 收尾（"谢谢"） | 大标题居中 |

**编排原则**：一页一个观点；要点 ≤ 3 个；一句话能说清的不用一段话；
支撑细节放备注（`<!-- notes: -->`），不放页面。

## 4. 主题与定制

`--theme` 三种内置外观（演示独立视觉语言，与文档 4 套主题不同形）：

| 主题 | 气质 | 适用 |
|---|---|---|
| `dark`（默认） | 深蓝紫渐变 + 白字 + teal 强调 | 技术分享、发布会（舞台感） |
| `light` | 白底墨字 + 靛蓝强调 | 会议室投影 |
| `warm` | 米白 + 暖棕 + 琥珀强调 | 课程、分享会 |

自定义 CSS 文件（与主题包同模式，覆盖 `--slide-*` 令牌）：

```css
:root {
  --slide-bg: #0b1020;           /* 页面背景（支持渐变） */
  --slide-accent: #f59e0b;       /* 强调色（进度条/链接/标题） */
  --slide-h1: 3.8rem;            /* 一级标题字号 */
}
```

## 5. 演示者功能（内嵌壳层，零依赖）

| 按键 | 功能 |
|---|---|
| `←` / `→` / `空格` / `PageUp` / `PageDown` | 翻页 |
| `Home` / `End` | 首/末页 |
| `F` | 全屏 |
| `S` | 演讲者备注视图（当前页备注 + 时钟条） |
| URL `#3` | 直达第 3 页（刷新保持） |

触屏：左右滑动翻页；点击右侧 85% 区域下一页。打印：每页一页纸。
`prefers-reduced-motion` 自动关闭切换动画。

## 6. 与文档的关系（同源不同形）

| | 文档 | 演示 |
|---|---|---|
| 形态 | 密度、可检索、SEO、Agent 读取 | 强视觉、逐页叙事、每页一观点 |
| 源 | `docs/*.md`（站点） | `talk.md`（独立编排） |
| 产物 | dev / SSG / bundle | 自包含单文件 `talk.html` |
| 复用 | 渲染内核（扩展语法一致） | 同一渲染内核 |
| 转换 | —— | **不做机械切页**：按叙事重写 |

Agent 编排演示见 [doclight-slides Skill](../.claude/skills/doclight-slides/SKILL.md)。
