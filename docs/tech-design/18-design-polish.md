## 4. 红线（每阶段自查）

1. 宪法反模式清单（§7）一条不碰；新视觉值全部走 token
2. 展示层体积：所有新增 JS 计入 <25KB gzip 硬门禁（ADR-0002）
3. 三形态同构（dev/SSG/bundle）：任何组件不得只在一形态生效
4. 无 JS 降级：SSR 直出内容完整可读（渐进式水合铁律）
5. 每次改动引用需求 ID；阶段完成必写交接文档并更新 CLAUDE.md/AGENT.md 当前状态
6. 滚动触发动画只出现一次；reduced-motion 全量降级
