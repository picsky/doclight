#### 版本切换器设计规格（DP-005 设计先行；实现随产品层版本数据接入）

> 现状：version-btn 为装饰性徽标（chrome.version 驱动）。目标：多版本文档切换入口。
> 数据源（产品层）：站点 manifest（docs.json 或 doclight.json）声明 versions 数组
> [{ version, label, url, current }]；无数据时按钮不渲染（现状保持，零回归）。

1. **形态**：顶栏 version-btn（现有位置）点击弹出下拉菜单——当前版本高亮打勾、
   可选版本链接、底部「全部版本」入口（缺省指向站点根/versions 索引页）
2. **浮层语言**：复用搜索弹层（--shadow-pop + 圆角 10px + 1px --line-strong 边框），
   宽 ≤200px、错峰入场 ≤250ms（宪法 §3.4）
3. **键盘**：Enter/Space 开合、↑↓ 选择、Esc 关闭、焦点陷阱（与搜索弹层同规范）；
   aria-haspopup="listbox" / aria-expanded 同步
4. **SPA 语义**：点击版本链接 = 站内导航（router 接管）；外链版本 target=_blank
5. **降级**：无版本数据 → 按钮不渲染；单版本 → 显示但菜单禁用（「已是当前版本」）
