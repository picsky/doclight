# 自定义容器

> 容器用 `:::` 围栏标记，**纯 CSS 呈现**（左侧语义色竖线 + 图标），无 JS 依赖；
> 即使脚本全部禁用，也降级为带样式的普通 div。

## 提示（tip）

:::tip
**适合放**：补充说明、快捷提示、最佳实践。

提示容器使用强调色（松绿）竖线与 ✓ 图标。
:::

## 警告（warning）

:::warning
**适合放**：注意点、易错项、行为变更提醒。

警告容器使用琥珀色竖线与 ⚠ 图标，提醒读者留神。
:::

## 危险（danger）

:::danger
**适合放**：破坏性操作、安全红线、不可逆变更。

危险容器使用红色竖线与 ✕ 图标——看到它请先停一下。
:::

## 信息（info）

:::info
**适合放**：背景知识、上下文说明、引用出处。

信息容器使用蓝色竖线与 ℹ 图标，安静补充背景。
:::

## 容器内的 Markdown

容器内部**支持完整 Markdown**：列表、代码、链接都可以：

:::tip
使用前请确认：

1. 语法已写对（`:::` 前后各留空行）
2. 容器嵌套层级不要太深
3. 与相邻块级元素用空行隔开

示例：`doclight dev` 预览 `doclight build` 发布。
:::

## 源码形态

下面是本页第一种容器的 Markdown 源码：

```md
:::tip
**适合放**：补充说明、快捷提示、最佳实践。

提示容器使用强调色（松绿）竖线与 ✓ 图标。
:::
```
