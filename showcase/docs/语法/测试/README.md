## 三个最重要的认知（先记住再读）

1. **dsh 给了「机制」，你给「内容、策略、流程」**——每层的工作没消失，从「实现机制」变成了「注入业务」
2. **产品差异化只剩三处**：知识质量（01）、流程设计（03）、迭代速度（07）——前两个是起点，最后一个是持续
3. **评估迭代不是上线前的环节，是日常开发循环**——评估集 + 迭代记录表是底线，不是可选项
