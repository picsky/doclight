# 09 · 从零到一产品路线图：把知识变成产品

> **读者**：准备动手的人。这份路线图把 01–08 篇织成 12 周的启动计划——每阶段有目标、关键动作、验收标准。
> **核心思想**：不是「先搭好再测」，而是「第一周就跑通最小闭环，然后加速迭代」（课程第 08 章的 Capstone 心法在这里产品化）。

---

## 总览：四阶段 12 周

| 阶段 | 周 | 目标 | 关键产出 |
|---|---|---|---|
| **MVP** | 1–2 | 跑通最小闭环 | 一个真实用例端到端可用 |
| **产品化** | 3–4 | 过程变产品 | 流式 UI + 审计 + 会话策略 |
| **可靠性** | 5–8 | 稳定可运营 | 评估集 + 约束 + 兜底 |
| **规模化** | 9–12 | 成本与并发可控 | 实例池 + 看板 + 迭代节奏 |

---

## 阶段 1：MVP（第 1–2 周）——跑通最小闭环

**目标**：一个真实用例，从用户输入到交付，端到端可用。

| 关键动作 | 对应知识 | 验收标准 |
|---|---|---|
| 定用例：一个具体任务（非「通用助手」） | 00 全景 | 一句话能说清任务与交付物 |
| 官方组合 + SDK 跑通 | `sdk-docs/02` | 一次 run() 出结果 |
| 写产品 AGENTS.md（≤50 行）+ persona | 01 | 模型行为符合预期 80% |
| 包装 2–3 个核心业务工具（先 CLI/薄桥接） | 02 | Agent 能完成业务操作 |
| 建错误日志 + 10 条评估用例 | 07 | 评估集能跑出基线 |

**验收**：`python -m your_product "真实任务"` 能在 5 分钟内出可用结果；评估集基线已记录。

**里程碑心智**：这一阶段结束，你已验证「这个用例在 dsh 上成立」——不成立就换用例，别恋战。

## 阶段 2：产品化（第 3–4 周）——过程变产品

**目标**：从「脚本能用」到「产品能用」。

| 关键动作 | 对应知识 | 验收标准 |
|---|---|---|
| 流式 UI（chunk → 前端） | 05 | 打字机效果 + 工具卡片 |
| 审计落库（tool/call + result） | 05 | 每次运行全证据可查 |
| 会话策略落地（session_id/session_root/归档） | 04 | 多任务隔离，恢复可用 |
| 审批/追问交互（工具层机制） | 06 | 危险操作有确认路径 |
| 业务流程编排（Python 循环或 workflow） | 03 | 流程可复现、可重试 |

**验收**：用户能通过产品界面完成一次完整任务（含流式反馈与审批交互）；审计日志完整。

## 阶段 3：可靠性（第 5–8 周）——稳定可运营

**目标**：错误率可控、失败有兜底、迭代有数据。

| 关键动作 | 对应知识 | 验收标准 |
|---|---|---|
| 评估集扩到 30+ 条（三类齐备） | 07 | 每类错误都有对应用例 |
| 错误 → 规则回流跑两轮 | 07 | 至少两轮「改一处→验证→记录」 |
| 工具精致化（schema/错误即修复） | 02 | 高频工具错误率显著下降 |
| 人工兜底路径（重试→降级→升级） | 03/06 | 升级时上下文打包可用 |
| 部署检查清单过一遍 | 08 | 清单全绿 |
| compaction 开启 + 阈值调优 | 04 | 长会话无 Dumb Zone 症状 |

**验收**：评估集通过率稳定；最频繁的 3 类错误都有对应防线；一次故障注入演练通过。

## 阶段 4：规模化（第 9–12 周）——成本与并发可控

**目标**：从「能跑」到「能运营」。

| 关键动作 | 对应知识 | 验收标准 |
|---|---|---|
| 实例池/并发架构落地 | 08 | 并发任务按预期完成，无泄漏 |
| 成本三层预算 + 看板告警 | 08 | 每任务成本分布可见，异常有告警 |
| 监控指标看板（reason 分布/步数/介入率） | 05/07 | 每周复盘有数据 |
| 升级流程演练一次 | 08 | 版本升级 + 冒烟 + 回滚走通 |
| 迭代节奏固化（每周闭环） | 07 | 连续 4 周有迭代记录 |

**验收**：稳定运行 2 周无重大事故；每周迭代闭环持续产出改进；成本模型可预测。

---

## 里程碑检查点（每阶段结束时自问）

| 检查点 | 通过标准 |
|---|---|
| 用例成立 | 真实任务端到端可用，不是 demo 玩具 |
| 产品成立 | 有界面、有反馈、有审计，不是脚本 |
| 可靠成立 | 有评估集、有兜底、有迭代记录 |
| 运营成立 | 成本可控、并发可靠、升级可演练 |

## 与课程六层架构的对应（学到的东西在哪落地）

| 课程六层 | 本路线图的落地 |
|---|---|
| L1 信息边界 | 阶段 1 的 AGENTS.md + persona（01 篇） |
| L2 工具系统 | 阶段 1/3 的业务工具（02 篇） |

| L4 记忆与状态 | 阶段 2/3 的会话策略 + compaction（04 篇） |
| L5 评估与观测 | 阶段 1/3/4 的评估集与看板（05/07 篇） |
