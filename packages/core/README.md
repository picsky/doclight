# packages/core — 公共类型与契约

> 状态：Phase 0 占位

## 为什么存在（意图文档，12 §4.1）

多包共享的**类型定义与常量**（doclight.json 配置类型、文档元数据结构、插件 API 类型）。避免各包重复定义导致漂移——类型即契约（12 §4.3）。

**为什么独立成包**：renderer（Node）与 display（浏览器）运行环境不同，但共享的「数据结构」定义应只有一份。core 零运行时依赖，可被任意包引用。

## 边界

- 只放类型、常量、纯函数；不放业务逻辑
- `doclight.json` Schema 的 TypeScript 类型以此为准，**只加不改**（12 §6.2）
