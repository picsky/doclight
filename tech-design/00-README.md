## 一句话定位

**DocLight 是一款服务于人阅读、同时 AI 原生友好的零构建开源文档站引擎。**

- 对人：极致阅读体验，双击即看，离线可用
- 对 AI：结构化、可搜索、可操作、可定制
- 对开发者：零构建、单文件、无锁入、易扩展

---

## 设计哲学

### 核心原则

0. **Agent-First（原则零）** — 一切设计决策先问「Agent 能否理解、使用、修改它」，再问「人是否方便」；几乎没有人手搓代码，产品与开发都以 Agent 为本
1. **内容是主角，工具是透明的** — 好的文档站让读者读完后记住了内容，记不起界面
2. **零构建优先，渐进增强** — 零配置即可用（三形态：dev 预览 / SSG 发布 / bundle 便携包），每一项高级功能都是 opt-in
3. **人阅读优先，AI 友好是天然副产品** — 清晰的结构、明确的语义，对人和对 AI 都好
4. **小而美内核 + 插件扩展** — 浏览器展示层 < 25KB gzip（渲染在 Node 侧），功能通过插件加载
5. **无锁入** — 内容是纯 Markdown，配置是 JSON，迁移成本为零
6. **Agent 可定制** — 从架构层面让 AI Agent 能轻松理解、使用、定制这个文档站，覆盖「使用端」（消费文档站的 Agent）与「开发端」（开发本产品的 Agent）双维度

### 反模式（我们不做什么）

- ❌ 不做臃肿的框架（Docusaurus 式的全家桶）
- ❌ 不做平台锁定（GitBook/Mintlify 式的 SaaS 围墙）
- ❌ 不做 AI 计量计费（行业差评集中地）
- ❌ 不做 Markdown 方言扩展（CommonMark + GFM 足够）
- ❌ 不做视觉过度设计（渐变、阴影、动效堆砌）
- ❌ 不做为人类开发者设计的开发流程（几乎没有人手搓代码，文档、错误信息、脚手架、CI 都以 Agent 为本）

## 关键数字

| 指标 | 目标 |
|---|---|
| 浏览器展示层体积 | < 25KB gzip（无 marked） |
| Node 渲染内核体积 | < 20KB gzip（不进入浏览器） |
| 首屏加载 | < 500ms（CDN，SSG 直出）；bundle 单文件双击即看 |
| SSG 构建速度 | 100 页 < 5 秒 |
| 搜索索引构建 | 100 页 < 200ms |
| 零配置可用 | 是（三形态：dev 预览 / SSG 发布 / bundle 便携包） |
| 产品形态 | 3 种，共享同一渲染内核（见 02） |
| 一键部署 | 支持（GitHub Pages / Cloudflare / Netlify），`doclight deploy` |
| 支持的 AI 协议 | llms.txt + MCP（使用端 + 开发端） |
| XSS 防护 | DOMPurify sanitize（强制，渲染源头处理） |
| 默认主题模板 | 4 套（Minimal / Serif / Modern / Warm），亮暗双主题 |
| 视觉质量保障 | 多断点视觉回归 + 像素级 diff + 设计合规检查 |
| 开源协议 | MIT |
