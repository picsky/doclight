DocLight 快速开始 #

DocLight 是一个把 Markdown 变成作品的开源文档站引擎。它零构建、AI 原生友好，专注于中文技术文档的阅读与导航体验。只需掌握标准 Markdown 与少量 frontmatter，即可在几分钟内发布一套精致的文档站点。

在阅读本文之前，请确保你已安装 Node.js 18+，并了解基本的命令行操作。如果你是第一次使用，建议按顺序完成下面的 旧版手动部署 新流程。

安装 DocLight #

打开终端，执行以下命令初始化项目：

  1. 使用 npm create doclight@latest 创建项目脚手架。
  2. 进入项目目录并安装依赖：npm install。
  3. 运行 doclight dev 启动本地预览服务。
  4. 在浏览器中访问 http://localhost:3000 查看效果。
bash
npm create doclight@latest my-docs
cd my-docs
npm install
npm run dev

创建第一篇文档 #

所有文档都存放在 docs/ 目录下。新建一个 .md 文件，即可开始写作。DocLight 支持标准 Markdown、GFM 扩展以及自定义容器。

  • docs/ — 文档源文件
  • public/ — 静态资源，如图片、字体、图标
  • doclight.config.js — 站点级配置
  • package.json — 项目依赖与脚本

配置站点 #

通过 doclight.config.js 可以修改站点标题、基础路径、输出目录等。下面是一份常见配置示例：

javascript
import { defineConfig } from 'doclight';
import { resolve } from 'node:path';

export default defineConfig({
  title: 'DocLight',
  description: '把 Markdown 变成作品',
  outDir: resolve('./dist'),
  basePath: '/docs',
});

每篇文档的 frontmatter 支持多个字段，用于控制标题、描述、分类、标签等。常用字段如下表：

字段 类型 默认值 说明
title string — 文档标题，用于导航与 SEO
description string — 一句话描述，影响搜索结果摘要
date string — 发布日期，影响 sitemap 排序
tags string[] [] 标签列表，用于检索过滤
priority enum medium high / medium / low，影响 llms.txt 分级
category string — 文档分类，用于目录分组

发布工作流 #

DocLight 的发布链遵循「写入先进预览态，发布前必须经人确认」的原则：

提示

本地开发时使用 doclight dev，所有修改会实时热更新，无需手动刷新浏览器。

信息

doclight build 会生成 SSG 静态产物，包含 llms.txt、docs.json、search-index.json 等。

警告

doclight publish 会直接修改线上产物，请在构建产物经预览确认后再执行发布。

危险

删除已发布文档会导致相关 URL 失效，搜索引擎缓存也可能需要一段时间才能刷新。

文档是思考的终点，也是协作的起点。把 Markdown 变成作品，是一件值得反复打磨的小事。

—— DocLight 设计原则
